# ADR-004: Queue State Machine

## Status
Accepted

## Context
Queue entry lifecycle must be consistent across customer, staff, and admin workflows.

## Decision
Model queue entries with an explicit state machine: Waiting, Calling, Serving, Completed, Cancelled, NoShow, and Transferred.

## Alternatives
Free-form status fields, event sourcing from day one.

## Consequences
Legal transitions are clear and testable. Adding new states requires an intentional migration and UI/API update.
