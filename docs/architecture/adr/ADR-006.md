# ADR-006: Deployment Strategy

## Status
Accepted

## Context
QueueIt must run reliably in cloud environments and support CI/CD.

## Decision
Deploy frontend, API, and workers as containerized workloads with managed PostgreSQL, Redis, object storage, CDN, and WAF.

## Alternatives
Bare VMs, serverless-only, single PaaS instance.

## Consequences
Deployments are portable and scalable. Operations must maintain images, secrets, migrations, and observability.
