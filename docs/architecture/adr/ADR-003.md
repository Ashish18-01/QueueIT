# ADR-003: Authentication Strategy

## Status
Accepted

## Context
The platform needs secure browser/API authentication with revocation and scalable authorization.

## Decision
Use short-lived JWT access tokens with rotating server-stored refresh tokens.

## Alternatives
Server sessions only, opaque access tokens, external identity provider only.

## Consequences
Access checks are efficient and refresh tokens remain revocable. Implementation must handle rotation, reuse detection, secure storage, and token expiry carefully.
