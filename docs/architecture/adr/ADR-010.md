# ADR-010: Error Handling Strategy

## Status
Accepted

## Context
The API must return consistent errors while preserving domain clarity and observability.

## Decision
Use typed domain/application errors mapped to stable API error responses with correlation IDs.

## Alternatives
Throw generic exceptions, expose raw framework/database errors.

## Consequences
Clients receive predictable errors and logs remain diagnosable. The error taxonomy must be maintained as features evolve.
