# ADR-009: Notification Strategy

## Status
Accepted

## Context
Notifications are important but should not make queue state changes fail when providers are slow.

## Decision
Publish notification requests through an outbox and process them asynchronously with workers.

## Alternatives
Send notifications inline, provider webhooks only, scheduled polling only.

## Consequences
Queue operations remain fast and resilient. Notification delivery becomes eventually consistent and needs retry/dead-letter handling.
