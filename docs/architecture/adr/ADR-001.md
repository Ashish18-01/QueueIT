# ADR-001: Architecture Style

## Status
Accepted

## Context
QueueIt needs maintainable architecture before implementation and must support future cloud scale.

## Decision
Use a modular monolith with Clean Architecture boundaries.

## Alternatives
Microservices, serverless-only, traditional MVC.

## Consequences
The system starts simpler while preserving module boundaries for future extraction. The team must enforce dependency rules and avoid shared-database-style coupling between modules.
