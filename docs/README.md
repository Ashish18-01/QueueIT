# QueueIt Documentation

This directory contains product, architecture, engineering, and delivery documentation for QueueIt.

## Phase 1 Documents

- `srs/software-requirements-specification.md` — product scope, functional requirements, non-functional requirements, business rules, API expectations, security requirements, testing requirements, and acceptance criteria.
- `adr/0001-incremental-enterprise-delivery.md` — decision record explaining why QueueIt will be delivered through governed phases rather than generated as a single monolithic implementation.

## Documentation Principles

QueueIt documentation is treated as an engineering artifact. Requirements, decisions, risks, and constraints must be explicit before implementation begins so that future code remains maintainable, testable, secure, and aligned with business needs.
